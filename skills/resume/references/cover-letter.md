# Cover letters

Facts follow the same Gate 0 rule as the resume: every claim traces to `profile/evidence.md`,
`profile/me.md` or the user's words this session. Voice follows `profile/voice.md` and the
`voice` skill; run `aislop` before the user sees it.

**Length target: half to three-quarters of a page (~280–340 words).** Recruiters skim; long,
adjective-heavy sentences read as AI-written within seconds.

**Research density: name 4+ specific product surfaces.** Abstract claims ("Acme ships fast") don't
count as company research. Naming four distinct products, features or customer segments does
("keeping the mobile app, the partner API, the analytics tier and the self-serve onboarding all
moving"). The number of named surfaces reads as a proxy for depth of research. Applies equally to
application essays and long-form outreach.

**Opener: an outside observation, then the user inside it.** A category claim the reader can't
argue with, then a pivot to first person, lands harder than an identity claim alone ("I'm
passionate about fintech"). Lead with something about the world, then name the user in it.

**Be the signal in the noise.** Answer "Why you?" early. Frame around *what they're building →
why the user's specific experience helps*, link a built artifact (portfolio piece, repo, case
study) where one maps, and ask before handing it over: "Is this the pitch I would say yes to?"

**Structure that works:**
1. Thesis / identity (what the user builds or does, one concept)
2. How they work (one sentence)
3. Experience arc (chronological, specific numbers, one anchor employer)
4. Lived-in story (one paragraph with concrete detail: the thread, the time-to-resolution, the
   customer)
5. Why this company (outside observation → personal use → named surfaces)
6. Closer (short and declarative)

**Checklist before shipping:**
- 0 placeholders (`X`, `XX`, `XYZ`, `[BRACKETS]`, `<…>`)
- Dash style and density as recorded in `profile/voice.md` / `profile/rules.md`; sign-off from `profile/voice.md` (none recorded → ask once)
- Grammar: subject-verb agreement on list subjects, pronoun-referent agreement on plurals
- Every superlative ("largest / first in X") verified against an external source
- `aislop` clean (no "superpower", no corporate filler)
- The strongest line in the draft is still there; if a requested edit weakens it, flag it
